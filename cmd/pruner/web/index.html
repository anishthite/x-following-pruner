X Following Pruner

Follow fewer people, deliberately.

Import your following list, inspect it locally, and decide what to do next. Nothing happens automatically.

Start here

  1. Set X_BEARER_TOKEN and X_USERNAME in .env.local.
  2. Run go run ./cmd/pruner fetch-following.
  3. Explore data/following.json.
Guardrail

This importer only reads your data from X. It does not follow or unfollow anyone.
